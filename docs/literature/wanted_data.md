# 文献から転記してほしいデータのリスト

方針(2026-08-09): スキャンを AI に読ませず、必要な数値をユーザーが紙面から
転記して持ち込む。転記時は **値・単位・表番号・ページ番号** をセットで
(data.py の source にページ番号まで記録する規律のため)。形式は自由(箇条書き/CSV)。

優先度順。P1 が揃うと「元素別 DH への移行」と「活量モデル較正」が動き出す。

---

## P1-1: Yang 2022, Inorg. Chem. 61, 7590(スキャン 0814)

**目的: LnOCl の元素別 DH(系列一定仮定からの脱却)の本命データ**

- [ ] 全 REOCl の生成エンタルピーの表(おそらく Table 2 か 3)。各 RE
      (La〜Lu, Y)について:
      **ΔH°f,298(元素基準)** と **酸化物+塩化物からの生成エンタルピー
      (1/3 RE₂O₃ + 1/3 RECl₃ → REOCl の ΔH)** の列。±誤差も。
- [ ] その表で使っている補助データの出典の脚注(あれば一行メモ程度で)

## P1-2: Niazi 2022, Materialia 21, 101296(スキャン 0808)

**目的: W(CuCl,KCl) を較正の `fixed` に入れる**

- [ ] 最適化パラメータの表(「optimized parameters」の表)。特に:
      液相の Redlich-Kister 係数 L⁰, L¹(J/mol、温度依存項があれば式ごと)、
      K₂CuCl₃ の G 式(ΔH_f と S° の数値)
- [ ] 計算相図の不変点(共晶 145.9 ℃ / 64.9 mol% CuCl、包晶 241.2 ℃ は
      抄録確認済み — 本文値が違えば訂正を)

## P1-3: Fontana 1952, IEC 44, 363(スキャン 0802)

**目的: 平衡塩素圧データ → `ClObservation` で活量モデル較正**

- [ ] まず教えてほしいこと: **塩素圧の結果は数値表か、図のみか**
      (1 ページ目の Table I/II は凝固点表。塩素圧は後のページのはず)
- [ ] 数値表があれば転記: 各点の **温度 [℃ or K]、KCl mol%、
      cupric copper %(または CuCl₂/CuCl 比)、p(Cl₂) [mmHg]**
- [ ] 組成ごとの log p vs 1/T の相関式が本文にあればその式
- [ ] 図のみの場合は転記不要。代表点を数点読み取ってもらうか、別途相談

## P2-1: Seifert 2002 レビュー, JTAC 67, 789(スキャン 0812)

**目的: K-Ln 複塩の熱力学(特に Sm — 未入手の Thiel & Seifert 1988 の代替)**

- [ ] **K 系(A=K)の熱力学表だけでよい**(Na/Rb/Cs は不要)。
      各 Ln(La, Ce, Pr, Nd, **Sm**, Eu, Gd)の K₃LnCl₆ / K₂LnCl₅ /
      KLn₂Cl₇(/K₃Ln₅Cl₁₈)について、記載の反応(nKCl + LnCl₃ → 化合物、
      または隣接化合物からの生成)の **ΔH° [kJ/mol]、ΔS° [J/mol/K]、
      ΔG°(T) の式(a + bT 形式)**
- [ ] **最優先は Sm の行**。Sm だけ先にもらえれば十分価値がある
- [ ] K₃LnCl₆ の安定下限温度(分解温度)の列があればそれも

## P2-2: Seifert 2006 レビュー, JTAC 83, 479(スキャン 0807)

- [ ] 同上の K 系の表(Tb, Dy, **Ho**, Er, Tm, Yb, Lu と、**Y への言及があれば Y**)。
      最優先は **Ho と Dy**(Y/Ho 対照と系列アンカー)

## P2-3: Koch 3 部作の要約定数(スキャン 0801, 0803x, 0804)

**目的: La/Pr/Nd/Sm/Gd の元素別加水分解定数(hydrolysis_K の直接実測)**

- [ ] **0801(Sm/Gd)最優先**: p.797 の Table III(La/Sm/Gd の 3 行)。
      各行 8 列: ΔF°₇₈₅, ΔH°₇₈₅, ΔS°₇₈₅, ΔF°₂₉₈, ΔH°₂₉₈, ΔS°₂₉₈, ΔH₀, I
      [ΔH は kcal/mol、ΔS は cal/(mol·K)]。+ Table I/II の測定温度域
      (最低-最高 T)と本文記載の平均偏差
- [ ] 0804(Pr/Nd): 冒頭要約の計算熱力学定数。
      PrCl₃: ΔF°₇₈₅, ΔH°₇₈₅, ΔS°₇₈₅ / ΔF°₂₉₈, ΔH°₂₉₈, ΔS°₂₉₈ [kcal, e.u.]。
      NdCl₃: 同上。+ 測定温度域と平均偏差
- [ ] 0803x(La): 要約の同定数(II 報の Table III と同値のはずなので、
      **違っていたときだけ**訂正値を)+ 測定温度域

## P3(あとで良いもの)

- [ ] 0803(Fontana 酸素圧, IEC 44, 369): 本文の平衡式 3 本の係数の確認
      (log K₁ = −7035/T + 10.28、log K₂ = 577/T + 1.892、
      log K₃ = −6250/T + 8.61 と読めたが要確認)+ それぞれの反応の定義。
      KCl 30 mol% 融液の CuO 溶解度の代表値(温度と mol%)
- [ ] 0817(Burns 1998): 全 Ln への LnOCl ΔH°f,298 推定表(本文 Table)と、
      推定に使った Ln₂O₃ / LnCl₃ の補助データ表
- [ ] 0815(Roffe & Seifert 1997, Ho): K₃HoCl₆ / KHo₂Cl₇(K₂HoCl₅ があれば

      298.15 K の酸化物+塩化物基準の ΔH_r/ΔS_r/ΔG_r(NdOCl, YOCl, TmOCl)。
      + TmOCl の ΔS_r(298) の値(プレプリントでは未転記)
