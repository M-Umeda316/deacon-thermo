# Ln 系列の実験計画（Cu-K-Ln/γ-Al₂O₃ の HCl 酸化）

生成日: 2026-08-10 / 予測値の出所: `examples/03_series_prediction.py`、
`deacon_thermo.lanthanides.survey()`（いずれも本リポジトリのコード実行）。
数値は `data.py` の当時の値にぶら下がっているので、data.py を差し替えたら
この文書の表も再生成すること。**特に寿命の列は CuCl₂(g) の S°/Cp
（2026-08-10 に統計力学値へ差し替え、`docs/cucl2g_statmech.md`）に直結しており、
同日中に 7.1e3 h から 2.5e3 h へ動いている。** 相・複塩の列は CuCl₂(g) に
依存しないので影響を受けない。

条件: 相の判定 380 ℃ (653.15 K)、HCl/O₂ = 2:1、平衡出口 p(Cl₂) = 0.325 atm
（平衡 HCl 転化率 83.8 %）。カチオン組成 Cu:K:Ln = 0.40:0.35:0.25。
寿命は参照系の報告条件に合わせて 340 ℃ (613.15 K)、p(Cl₂) = 0.32 atm、
融液 CuCl+CuCl₂ 1 : KCl 1.0 : LnCl₃ 0.3、GHSV 6000。

---

## 1. 目的と設計思想

この計画は「Ln を変えると何が動くか」を、**軸A（Ln 自身の酸化還元: Ce/Pr/Tb が +4、
Eu が +2 に届き第二の酸化還元中心になる）と軸B（イオン半径＝ランタノイド収縮が
塩化物イオン活量・複塩安定性・Cu 活量係数を連続的に動かす）を混ぜずに**測るために
組んである（CLAUDE.md）。軸を混ぜた系（例えば Ce と Er を同時に振る）を測ると、
性能差が酸化還元機構の変化なのか融液化学の変化なのか原理的に分離できない。
したがって主系列は軸B の酸化還元不活性な Ln（La, Nd, Sm, Gd, Ho, Y）で組み、
軸A は Ce 一点を「予測が外れることを期待する対照」として置く。さらに
Y (4f⁰) と Ho (4f¹⁰) がほぼ同半径（0.900 / 0.901 Å）であることを使って、
効果がイオン半径・ルイス酸性で尽きるか 4f が関与するかを決定する。

## 2. 候補系のマトリクス

余裕 = `chloride_margin`（正なら単一金属では LnCl₃ が安定、負なら LnOCl 側）。
相分配は参照カチオン組成での `stable_assemblage`（Ln の何 % がどの相にいるか）。
寿命帯は W(Cu-LnCl₃) を −10 / 0 / +10 kJ/mol で振ったときの Cu 半減時間。

| Ln | 軸 | r [Å] | 余裕 [kJ/mol] | 相分配（Ln 基準） | 塩化物分率 | K3LnCl6 下限 [K] | 寿命帯 [h] |
|----|----|-------|--------------|-------------------|-----------|------------------|-----------|
| **Sm**（参照） | B | 0.958 | −22.7 | K₂SmCl₅ 70 % + SmOCl 30 % | 0.70 | 606（L/H 転移） | 2.55e3 / 2.47e3 / 2.40e3 |
| La | B（大半径端） | 1.032 | **+5.5** | K₂LaCl₅ 57 % + K₃La₅Cl₁₈ 43 % | **1.00** | 未登録（K₃LaCl₆ は存在しない） | 同上 |
| Nd | B | 0.983 | −13.1 | K₂NdCl₅ 70 % + NdOCl 30 % | 0.70 | 169（合成 dG=0） | 同上 |
| Gd | B | 0.938 | −26.3 | K₂GdCl₅ 70 % + GdOCl 30 % | 0.70 | 636（L/H 転移） | 同上 |
| Ce | **A** | 1.010 | −1.0 | K₂CeCl₅ 70 % + CeOCl 30 % | 0.70 | 310（合成 dG=0） | 同上 |
| Ho | B / 対照 | 0.901 | −44.7 | KCl + HoOCl 100 % | 0.00 | データ無し | 同上 |
| Y | B / 対照 | 0.900 | −54.1 | KCl + YOCl 100 % | 0.00 | データ無し | 同上 |

**寿命帯が 7 系とも同一なのは予測ではなく較正の欠落である。** 融液モデルの
較正が効いているのは Cu-K 系（Fontana + Niazi）だけで、LnCl₃ は現状ただの
理想希釈剤だからである。この列に系列差を出すには W(Cu-LnCl₃) の較正が要る
（§4 の循環設計を参照）。

**「70 %」は Ln の性質ではなく K の予算である。** K:Ln = 0.35:0.25 = 1.4 で
K₂LnCl₅ は K を 2 消費するので、K を使い切った時点で Ln は 0.175/0.25 = 70 %
しか塩化物として係留できない。La だけが 100 % に届くのは、K を 0.6/Ln しか
使わない K₃La₅Cl₁₈ が LaOCl に勝つためで、これは La 固有の熱力学差である
（Ce にも K₃Ce₅Cl₁₈ は登録済みだが CeOCl に負ける）。

### 各系で何が判別できるか

**La vs Sm — オキシ塩化物の共存は活性に効くか。**
モデルは La で Ln の 100 % が塩化物複塩、Sm で 70/30 共存と予測する。
両者の活性・寿命が同等なら「オキシ塩化物は失活相ではない」（文献の La 系で
LaOCl・LaCl₃・中間塩素化度がいずれも活性、という報告と整合）ことが確定し、
以降の系列比較は相分配ではなく融液側の記述子で回せばよくなる。差が出るなら
相分配が一次記述子であり、`chloride_fraction` が回帰の主軸になる。
なお La は「単一金属でも塩化物側に残る唯一の元素（+5.5 kJ/mol）」で余裕が
薄いので、床の軸方向で相が変わっていないか急冷 XRD で位置分解して見る価値がある。

**Nd vs Sm — K₃LnCl₆ の操業温度安定性が逆であること。**
参照組成（K/Ln = 1.4）では両者とも K₂LnCl₅ で見分けがつかないが、K 過剰の
局所組成（K:Ln = 3）では判定が割れる: Sm は K₃SmCl₆ が K₂SmCl₅ + KCl に
608.8 K で勝ち始め、380 ℃ = 653 K では 2.8 kJ/mol 有利。Nd は同じ交差が
714.3 K なので 653 K では 4.2 kJ/mol 負けたままで、K₃NdCl₆ は現れない。
（記述子 `k3lncl6_limit` は定義が別で、Sm 606 K = L/H 転移点、Nd 169 K =
二元塩化物への分解下限。操業上効くのは上の K₂LnCl₅ + KCl との交差のほう。）
Sm の交差点 608.8 K は操業温度のわずか 45 K 下なので、**Sm 系は降温・
ホットスポット後の降温で K₃SmCl₆ を失う可能性があり、Nd 系はもともと持たない。**
昇降温サイクル（例えば 380 ℃ ⇄ 320 ℃）を挟んだ前後で Sm 系だけ活性・
XRD が変化し Nd 系が変化しなければ、K₃LnCl₆ が実際に働いている証拠になる。
逆に両者とも変化しなければ、K の役割は K₂LnCl₅ 止まりということ。

**Ce — 軸A（CeO₂ 化）の検証。**
モデルは Ce を軸B の元素として扱った場合の予測（K₂CeCl₅ 70 % + CeOCl 30 %、
余裕 −1.0 kJ/mol で境界上）しか出せない。CeO₂/CeCl₃ の酸化還元は候補相に
未実装だからである。したがって **Ce の相分配予測が外れる（XRD で CeO₂ が出る、
あるいは活性が軸B の半径トレンドから外れる）こと自体が、軸A の機構が効いている
直接の証拠**になる。当たってしまった場合は、Deacon 条件では Ce(IV) に届いて
いないということで、軸A の検証には Pr か Tb に移す必要がある。

**Y vs Ho — 4f の決定実験。**
半径がほぼ同一（0.900 / 0.901 Å）で Y だけ 4f を持たない。触媒性能（活性・寿命・
相分配）が一致すれば Ln 効果はイオン半径とルイス酸性で尽き、記述子を半径 1 本に
畳めることが確定する。違えば 4f（f 電子の分極率、配位場、あるいは酸化還元）が
関与しているので、記述子に元素別項が要る。
**正直に書いておくべき点:** モデル側の余裕は Y −54.1、Ho −44.7 で 9.4 kJ/mol
違っており「熱力学的に同一」ではない。ただしこの差の 3.3 kJ/mol は dS の
フレーム差に由来する（Y の dS = +9.4 J/mol/K は Gibson 2025 系＝磁気エントロピーの
扱いが違うフレーム、Ho の +4.3 は Koch 系実測 5 元素の平均という代用値。
653 K × 5.1 J/mol/K = 3.3 kJ/mol）。dH 側の差 3.1 kJ/mol も測定不確かさ
（±0.7〜0.8）より大きいが桁は同じで、残り約 2.9 kJ/mol は LnCl₃/Ln₂O₃ の
補助データ差である。**つまり予測差 9.4 kJ/mol のうち少なくとも 1/3 は
実体ではなくデータ系の不整合。** 両系の相分配はどちらも LnOCl 100 % と
予測されるので、実験で相が一致することは確認できる。性能差が出た場合、
それを 4f に帰属する前に「Y の dS フレームを Koch 系に揃えたらどうなるか」を
先に潰すこと。

**Gd — 系列内挿の検証点。**
LnOCl の生成量が Koch（加水分解平衡実測、−49.9）と Yang 2022（熱量測定、
−48.57±0.70）の両系統で 1.3 kJ/mol 一致している、系列中もっとも確からしい元素。
Gd がモデルの La-Sm-Gd トレンド上に乗れば、`dh_oxychloride` を記述子として
使ってよいことの検証になる。乗らなければ、外れているのは熱力学ではなく
熱力学と性能をつなぐ部分（担持・分散・融液）だと切り分けられる。

## 3. 測定項目と判定基準

| 測定 | 手法 | 判定基準 |
|------|------|---------|
| HCl 転化率 | 出口ガス滴定 or オンライン IR。380 ℃, HCl/O₂ = 2:1 | 平衡転化率 83.8 %(380 ℃) / 87.9 %(340 ℃) に対する比で見る。生の転化率で系列比較しない（平衡が温度で動くため） |
| 寿命 | 定常運転での転化率低下 + 使用後触媒の Cu 量（ICP-OES）、可能なら重量減 | モデルの絶対値（GHSV 6000 で 2.5e3 h、報告条件の GHSV 450 に直すと 3.3e4 h。参照系実測は ≥9600 h）は桁の議論にしか使えない。**系列内の相対比のみ使う**。GHSV を揃えずに寿命を比べないこと（寿命は 1/GHSV に比例する） |
| 急冷後 XRD | 反応温度から急冷（液体窒素 or 送風）→ 不活性雰囲気移送 → XRD | 相分配予測の直接検証。検出対象は K₂LnCl₅ / K₃LnCl₆（および La の K₃La₅Cl₁₈）と LnOCl。Su 2018 (IECR 57, 7795) が KCl-CuCl₂ 融液の急冷 XRD で KCuCl₃ / K₄Cu₄OCl₁₀ を捉えた前例がある |
| 出口ガス中 Cu | 出口配管のコールドトラップ + ICP、または下流での凝縮物回収 | 揮発の直接測定。§4 の W(Cu-LnCl₃) 較正にはこれか ICP による Cu 残存量が要る |
| （補助）床の軸方向分解 | 床を 3 分割して個別に XRD/ICP | 余裕が薄い系（La +5.5、Ce −1.0）で床内の相変化を見る。転化率に沿って p(HCl)²/p(H₂O) が動くため |

**急冷 XRD の解釈上の注意（両方向に効く）**: Su 2018 の著者自身は KCuCl₃ と
K₄Cu₄OCl₁₀ を「冷却中に生成したもの」と解釈している。したがって
**急冷試料に複塩が見えても反応温度でその相だったことにはならない**。
逆に Ghosh らは急冷試料中に K₃NdCl₆ を検出できておらず（Seifert 系と
Zhang 系で K₃NdCl₆ の室温安定性の報告が割れている、
`docs/literature/complex_salts_K_Ln_Cu.md` §5-2）、**見えないことも
「反応温度で存在しない」の証拠にはならない**。したがって XRD 単独では決めず、
冷却速度を 2 水準（急冷 / 徐冷）振って差を見る、あるいは可能なら
in-situ / operando の回折・Raman に寄せること。相分配の判定を XRD 1 本に
賭けない設計にしておく。

判定の順序: まず XRD で相分配予測が当たっているかを確定させ（当たっていれば
熱力学モデルは使える）、そのうえで活性・寿命の系列差を記述子に回帰する。
XRD が外れている系（Ce を期待）はモデル外の機構として別扱いにする。

## 4. 回帰の設計

n ≈ 15（Ln 系列全体でもこの規模）なので GNN は不適で、線形モデル + 交互作用
1 項、または RBF カーネルの GP が適切（CLAUDE.md）。

**記述子**（`LanthanideDescriptors.as_row()` がそのまま特徴量行になる）:

- `r_ionic` — イオン半径。軸B の主軸
- `dh_oxychloride` — LnOCl 生成反応の元素別 dH。系列共通値を使うと Dy の
  順位アーティファクトのような偽トレンドが出るので、必ず元素別値を使う
- `redox_active` — 軸A のフラグ。**軸A の元素を軸B の回帰に混ぜないための
  ゲートであって、連続変数として効かせるものではない**
- `k3lncl6_limit` — 複塩系の Ln のみ。K の係留能力の代理
- （派生）`chloride_fraction` — 相分配。実験の XRD と直接突き合わせられる

**重み付け**: `lnocl_confidence` を使う。現状 fair が 8 元素（Koch 5 + Yang 3）、
estimate が 3 元素（Ce/Eu/Dy、比-内挿法 ±3 kJ/mol）。estimate 元素は
分散を大きくとる（GP なら観測ノイズ、線形なら WLS の重み 1/σ²、σ ≈ 3 kJ/mol）。
La は Koch と Yang が 13 kJ/mol 食い違っているので、`dh_oxychloride` を使う
回帰では La を感度解析対象にしておくこと（両方の値で回して結論が変わらないか）。

**欠測の扱い**: `k3lncl6_limit` が None、`chloride_fraction` が 0.0 の重希土
（Dy, Ho, Er, Y）は **「複塩が存在しない」ではなく「Seifert 2002 Table 8 に
記載が無い」**。0 として回帰に入れると「重希土は複塩を作らない」という
存在しないトレンドを学習する。欠測として落とすか、複塩を使う項は
La-Gd のサブセットでのみ回すこと。Y については Seifert & Büchel 1998 が
未入手（CLAUDE.md 作業優先順位 2）で、これが入ると Y/Ho 対照の片割れが埋まる。

**寿命についての循環設計（重要）**:
現状モデルは **Ln に依存しない寿命しか出せない**（§2 の表で 7 系とも同一）。
W(Cu-LnCl₃) が未較正で、LnCl₃ が理想希釈剤としてしか入っていないためである。
したがって寿命は「予測を検証する量」ではなく「モデルを較正する量」として設計する:

1. 7 系の実測寿命（あるいは Cu 残存率）を取る
2. 系列差を `redox_split` + `lifetime` に食わせて、各 Ln の W(Cu-LnCl₃) を逆算する
3. 逆算した W を半径に対してプロットし、単調かどうかを見る。単調なら
   経験的に外挿でき、未測定 Ln の寿命予測が初めて可能になる
4. Ruthven & Kenney (JINC 30 (1968) 931) の四元系データが入手できたら、
   独立に較正した W と 2 の逆算値を突き合わせる（これが唯一の検証経路）

この設計では **寿命の系列差そのものが W(Cu-LnCl₃) の定義になるので、
同じ寿命データでモデルを検証してはいけない**（循環）。寿命の検証は
上の 4、または「較正した W で相分配や転化率など別の量が当たるか」で行う。

**実施順序の提案**: Sm（参照、既存条件の再現） → La → Nd → Ce の 4 点をまず取り、
XRD で相分配予測の当否を決める。ここで熱力学モデルが使えると分かってから
Gd（内挿検証） → Y/Ho（決定実験）に進む。Y/Ho を先に振ると、差が出たときに
4f のせいかモデルが端から外れているのか分離できない。

## 5. モデル側の既知の限界

`examples/03_series_prediction.py` の末尾の注意書きと同じ内容。実験結果と
食い違ったときに真っ先に疑うべき順に並べてある。

1. **融体が候補相に無い。** `assemblage` の候補は固体のみ。380 ℃ では Cu-K
   塩化物は実際には融体で、K₂CuCl₃(s) はその代理でしかない（241 ℃ 以上で
   包晶分解する）。Cu/K-rich 側の相分配は固体近似であり、液相線は未実装。
   本気で計算する段階になったら pycalphad + MQMQA に移る。
2. **CuCl₂(g) の dHf が要検証。** 反応条件での支配蒸気種でありながら
   JANAF/WebBook に気相熱化学が無い。S°/Cp は 2026-08-10 に分光定数からの
   統計力学値（±4 J/mol/K、`docs/cucl2g_statmech.md`）に差し替え済みだが、
   **dHf = −43 kJ/mol は依然 ESTIMATE で、寿命の絶対値はこの 1 個の数に
   人質に取られている**（この差し替えだけで寿命が 2.8 倍動いた）。唯一の
   一次資料候補は Wächter & Schäfer, ZAAC 471 (1980) 38（未入手）。
   **寿命は桁と系列内比のみに使うこと。**
3. **重希土の K 系複塩データが無い。** Seifert 2002 Table 8 は La-Gd まで。
   Dy/Ho/Er/Y の `chloride_fraction` = 0 は欠測であって予測ではない（§4）。
4. **W(Cu-LnCl₃) 未較正**（§2, §4）。寿命に系列差が出ない直接の原因。
5. **軸A の相が未実装。** CeO₂ / PrO₂ / Eu(II) 系が候補相に無いので、
   Ce/Pr/Tb/Eu の予測は「軸B の元素として扱ったら」の値でしかない。
6. **La の dH に 13 kJ/mol の文献不整合**（Koch −60.4 vs Yang −73.5）。
   反応温度域を直接測る Koch を採用中だが、**La の余裕 +5.5 kJ/mol は
   この選択に完全に依存する**。Yang 値を採れば LaOCl が 13.1 kJ/mol 安定化して
   余裕は約 −7.6 kJ/mol、つまり「単一金属でも塩化物側に残る唯一の元素」という
   La の特別扱いが消える。§2 の La vs Sm 比較は、この不整合が実験で
   決着する（La 系の急冷 XRD で LaOCl が出るか出ないか）ことも兼ねている。
